# 📚 lanqiao-algorithm
蓝桥杯 & 洛谷 & LeetCode & Codeforces 算法刷题仓库，记录算法学习与备赛全过程

---

## 🎯 仓库简介
本仓库用于系统整理**蓝桥杯备赛、洛谷、LeetCode、Codeforces 多平台刷题**的代码与思路，按算法分类归档，方便复习、复盘与查阅。

---

## 📂 目录结构
├── 01-basic/              # 基础算法（排序、二分、前缀和、双指针等）
├── 02-search/             # 搜索算法（DFS、BFS、回溯、剪枝等）
├── 03-dp/                 # 动态规划（背包、线性 DP、区间 DP 等）
├── 04-greedy/             # 贪心算法
├── 05-math/               # 数学与数论（GCD、快速幂、组合数等）
├── 06-string/             # 字符串处理（KMP、哈希、字典树等）
├── 07-data_structure/     # 数据结构（栈、队列、并查集、线段树等）
├── 08-graph/              # 图论（最短路、最小生成树、拓扑排序等）
├── 09-simulate/           # 模拟与暴力
├── 10-practice_real_ques/ # 真题与套题（蓝桥杯省赛 / 国赛、洛谷试炼场等）
└── README.md              # 仓库说明

## 🏷️ 平台前缀约定（文件命名）
统一格式：`平台前缀_题号`，按**考点**归入对应目录，平台信息由前缀区分：

| 前缀 | 平台 | 示例 |
| --- | --- | --- |
| `LG_` | 洛谷（含 B 题号的 GESP / 语言月赛题） | `LG_P1226.c`、`LG_B4071.c` |
| `LC_` | LeetCode | `LC_452.cpp` |
| `CF_` | Codeforces | `CF_1971A.cpp` |

## 📝 刷题规范
### 1. 文件命名
统一格式：`平台前缀_题号.c/.cpp`（例：`LG_P1226.c`、`LC_452.cpp`、`CF_1971A.cpp`），见上方前缀约定表。

### 2. 代码规范
- 代码添加注释，标注**题号、考点、解题思路、时间复杂度、空间复杂度**
- 统一使用标准头文件，避免冗余代码
- 关键算法步骤单独标注，方便复习

### 3. 提交规范
每次提交说明清晰，格式示例：`feat:xxx` / `fix:xxx`
